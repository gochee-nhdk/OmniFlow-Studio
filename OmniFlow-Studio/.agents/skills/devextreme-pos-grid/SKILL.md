# DevExtreme POS Grid & RPFO Portal Automation

1. **9-Step Outlet Initialization Settlement**: After selecting an outlet card (e.g., `FM04 - Hoàng Hoa Thám`) on `/shop/select-outlets`, wait up to 35 seconds for the 9 sequential initialization steps (`Loading Information Shop...` through `Loading Default Customer...`) to complete and redirect to `/admin/dashboard`. Never reload the page during this initialization window.
2. **In-App SPA Menu Navigation**: Navigate via `MORE` -> `Report` -> `Inventory Onhand` or `Sales Transaction Detail` first to preserve Angular in-memory state, using direct URL navigation only as a fallback.
3. **Extended Wave & Loading State Polling**: Wait up to 90 seconds per search attempt on `Inventory Onhand` (up to 6 retries if `No data` is returned after wave completion) and up to 120 seconds on `Sales Transaction Detail` while `.dx-loadpanel`, `.loading-wave`, or `button:has-text("Loading data")` is active.
4. **16 Standard Sloc IDs & Virtual Scroll Multi-Select**: Use `columnOption(field, 'filterType', 'include')` and `columnOption(field, 'filterValues', vals)` when the `dxDataGrid` API exposes matching columns; in DOM popup mode, traverse the `.dx-scrollable-container` virtual list to check all 16 standard Sloc IDs (`SDC0101`, `SDC0107`, `SDC0201`, `SFF0101`, `SFM0101`..`SFM1201`, including `SFM06QT1` and `SFM07AP1`) without resetting prior selections.
5. **Extended Exporting Modal Capture**: Poll captured `URL.createObjectURL` blobs and Playwright download events for up to 25 seconds across the 6-7 second `Exporting...` modal.
