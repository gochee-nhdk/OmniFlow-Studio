# DevExtreme POS Grid

Treat the `dxDataGrid` widget as the source of truth when its API is available. Resolve columns by data field and caption, apply inclusion filters as arrays, refresh the grid, and wait for load panels to finish. For header-filter popups, search and select every requested store or Sloc without clearing earlier selections. Commit `dxDateBox` values using local calendar dates, dispatch input/change events, and press Enter then Tab before searching. Verify the visible grid reflects the requested dates and filters before exporting.
