2. **SAML2 `/dispatcher/saml2/sp/acs` NullPointerException Auto-Recovery**: When SLD redirects to `/dispatcher/saml2/sp/acs` and throws `while trying to invoke the method com.sap.security.saml2.cfg.interfaces.SAML2SPConfiguration.getLocalSP() of a null object loaded from local variable 'configuration'`, NEVER reload `/saml2/sp/acs` (which triggers `Resubmit the Form?` and repeats the crash). Immediately navigate to the root Dispatcher URL (`https://<host>:8100/dispatcher/`) to consume the active SLD session cookie.
3. **Browser Access Thin-Client Initialization Wait**: Allow up to 22-25 seconds for the circular blue loading spinner on `/dispatcher/` to render the SAP Business One Browser Access workspace (`Công ty TNHH Thương Mại LARIA | LOG32`).
4. **Query Manager Pricelist Export (`QUERY_PRICELIST`)**: Open `Query Manager` -> select category `Danh Mục` -> select `Danh sách item ncc pricelist_non_Asset` -> click `OK` -> click `Export to MS-EXCEL` -> confirm `Save As` (`*.txt` / `OK`) -> confirm `Export currency symbols?` (`Yes, to the same column` / `OK`) -> wait ~12 seconds for file download (`Operation completed successfully [Message 200-48]`).
